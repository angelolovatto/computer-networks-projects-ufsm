# Computer Networks Projects — UFSM

Portfolio overview of academic work developed in **Computer Networks** at the **Federal University of Santa Maria (UFSM)**.

The coursework included medium-access protocols, discrete-event simulation, TCP/IP analysis, routing, packet inspection, and SCHC experimentation for constrained networks.

## Selected projects

### SCHC / OpenSCHC experimentation
Practical experimentation with **Static Context Header Compression (SCHC)** and fragmentation concepts for LPWAN/IoT environments. The portfolio includes my execution logs and screenshots from the experimental environment.

### Medium Access Protocol Simulations
Simulation and analysis of **ALOHA, Slotted ALOHA, CSMA, CSMA/CD, MACA, and Ethernet/Binary Exponential Backoff**, focusing on throughput, collisions, latency, and channel utilization.

### TCP/IP and Wireshark
Client-server experiments and packet analysis involving Ethernet, IPv4, TCP, UDP, DNS, and ICMP.

### Dijkstra Routing
Graph-based routing experiment applying Dijkstra's algorithm to a multi-node network topology.
